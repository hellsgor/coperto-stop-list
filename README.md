# Панель стоп-листа кухни

Тестовое задание для позиции Middle Frontend (React / Next.js) в Coperto.

## Задача

Один экран для менеджера зала: список позиций меню смены с фильтрами по
цеху и статусу, постановка позиции в стоп-лист (с причиной и сроком) и
снятие с него. Изменение статуса происходит оптимистично — сразу на
экране, без ожидания ответа сервера, — а мутации сервера иногда завершаются
ошибкой, после которой строка откатывается к прежнему состоянию.

Данные отдаёт мок-бэкенд на route handler'ах Next.js с искусственной
задержкой и случайными сбоями, имитирующими нестабильную сеть.

## Стек

Next.js (App Router, Turbopack), React, TypeScript (strict), Tailwind CSS,
TanStack Query, Zustand, React Hook Form + Zod, `motion`, Jest + Testing
Library.
